Setting up a sheet

Row 1 holds the headers. One column holds page addresses: name it URL (or Link, Page, Website — several spellings are recognised, and failing that the first column whose first value starts with http). Every other header is a field you want filled, written in plain words: price, in stock, delivery time. The add-on writes two columns of its own, Status and Checked. A header starting with # is yours and is never touched.

Then Extensions → Sheetwatch → Fill / refresh now.

What the Status column is telling you

  • ok — the page was read.
  • Nothing found — the page was fetched but nothing matching your column names was on it. Usually a column named something the page does not say, or a page that needs a login. Rename the column to the words the page itself uses and try again.
  • Page is gone — the address now redirects elsewhere; the item is no longer listed. The row is left alone and costs nothing to keep.
  • Still working: row N of M — Google stops any script after six minutes, so a long sheet is read in pieces. It carries on by itself about a minute later. Nothing is needed from you, and pressing refresh again only re-reads rows that are already done.
  • Connect your account — no key yet, or the key was replaced. Use Connect account in the menu.
  • Out of credits — top up at scrapewright.app/account.
  • Temporary error, will retry — our side, not yours. The row is read on the next pass.

Things people ask

A cell went empty and turned yellow. The page was read and the value is no longer on it — a price withdrawn, an item sold. That is a change like any other, so it is logged and highlighted. The old value is in the cell's note. A watch that kept showing yesterday's price would be reporting a price nobody is asking any more, which is the one thing it exists not to do.

A row says "Nothing found" and I think the page is fine. We remember a page we could not read and stop charging for it, so refreshing will not try again. Try the pages that found nothing again in the menu asks us to pay for another look. It is a separate menu item because it costs credits and an ordinary refresh does not.

What does a refresh cost? A page already learned costs one credit per row, plus five if it has to be rendered in a browser. Learning a new site costs more, once. A forty-row sheet of familiar shops is usually well under a hundred credits, and the free monthly allowance is a thousand.

A price here does not match the price I see. Check whether the shop sets VAT by the visitor's country — Odoo shops do this, and so do many others. We read pages from a machine in Paris, so such a shop quotes us the French rate of 20%, while you looking from Brussels see 21%. On a €594 machine that is €713.16 against €719.10: close enough to look right and wrong by six euros.

This affects only shops that vary the displayed price by country. A shop with one price for everyone reads correctly everywhere. If it matters to your sheet, say so — reading from a machine in the right country is a change we can make, and knowing which countries you need is what decides where.

Can I refresh automatically? Refresh every day in the menu, which runs each morning. Rows that answered "Nothing found" or "Page is gone" are skipped by the scheduled run so it cannot quietly spend your credits on pages that will not answer.

Reporting a problem

Email the address above with the page address, the column name, and what you expected. If a whole run misbehaved, say roughly when it ran — every request is timestamped on our side and that is usually enough to reconstruct it exactly.

Bugs in the add-on itself can also be raised at GitHub.

Deleting your data

Remove the add-on, or revoke its access at myaccount.google.com/permissions. To delete the account behind your key as well, see the privacy notice.
